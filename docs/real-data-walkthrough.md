## 一、数据形态

- **维度**：渠道品牌 / 运营模式（加盟·直营）/ 一级渠道（大区）/ 二级渠道（分公司·加盟主体）——两级归因维度现成。
- **指标**（6 组，每组 本期值/同期值/同比）：会员零售额、会员购买人数、会员开卡人数、零售额、新会员购买人数、新会员复购人数。
- **粒度**：**单期周报截面**（本周 vs 去年同期），无历史时序——与 M1 演示数据假设的"14 天日序列"不同（见"四、接口差距"）。

## 二、数字自洽校验（132 个同比声明）

131 个通过重算；**1 处源数据错误**：直营·浙江分公司的 `零售额同比` 声明 -1.3415%，按本期/同期值重算为 -1.9144%（差 0.57pt）。结论：源系统导出的同比列不可全信，**M2 必须落地"接入即校验"**（proposal 架构原则），重算同比而非直接用声明值。

## 三、这份数据能产出什么决策结论（信噪比预估：高）

整体（合计口径）：

| 指标 | 本期 | 同比 |
| --- | --- | --- |
| 会员零售额 | 1.41 亿 | **+8.81%** |
| 会员购买人数 | 33.96 万 | +8.78% |
| 会员开卡人数 | 16.45 万 | -1.22% |
| 零售额（大盘） | 2.40 亿 | **-5.89%** |
| 新会员购买人数 | 15.56 万 | -1.76% |
| 新会员复购人数 | 6,650 | -0.55% |

可直接生成的决策级结论（M2 检测+归因规则的目标形态）：

1. **【高】会员零售额 +8.8% 与大盘零售额 -5.9% 背离**：会员盘子逆势增长是唯一引擎，但开卡 -1.2%、新会员购买 -1.8%、复购 -0.6% —— 增长依赖存量会员购买人数，拉新与复购在萎缩，需决策"新客预算是否加码"。
2. **【高】会员零售额 +1,141 万偏离的归因**：西南加盟 +38.7%、广州子公司 +25.4% 拉动；鲁苏加盟 -23.5%、湖北加盟 -10.4% 拖累。注意"鲁苏分公司"存在加盟/直营两个主体（-14.98% vs +88.5%）——**归因维度必须带运营模式**，只看二级渠道名会互相抵消。
3. **【中】交叉异动**：新零售运营组 开卡 +21.3% 但会员购买人数 -72.2%——拉新在涨、转化在崩，典型的渠道质量或口径问题，值得人工核查。
4. **【规则设计警示】小基数噪声**：|同比|≥30% 的格子极多（湖北直营 +239.9% 基数仅 66 万；复购人数几十人的渠道 ±100% 常见）——印证红队 KA2：纯阈值规则会被小基数淹没，M2 规则必须带**规模门槛**（如 偏离绝对值 ≥ 总盘 1% 或基数 ≥ N 人才告警）。
