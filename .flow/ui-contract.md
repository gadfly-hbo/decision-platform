## 1. 窗口与布局骨架（三栏工作台 shell + S15 汇报模式覆盖层）

```
┌──────────────┬─────────────────────────────────────────────┬────────────┐
│ S-L 项目导航   │ 主内容区（= 当前项目的看板）                     │ S-R 运行详情 │
│ 固定 ~240px   │ ┌ S1 项目概览头 ……[汇报模式][运行详情]开关      │ 可开关抽屉   │
│              │ │ S1b 报告区：[上传报告] + 项目内报告列表        │ 默认收起    │
│ [＋ 新建项目]  │ │ S6 过滤器 + [补充建议]                      │ 模型链/账本  │
│ 项目列表       │ │ S2 行动项卡片流（卡内 S3/S4/S5/S12）         │ /事件时间线  │
│ (计数/活动/×) │ └ 全局保存失败 alert ────────────────────┘   │            │
└──────────────┴─────────────────────────────────────────────┴────────────┘
        ▲ S15 汇报模式 = fixed 覆盖层（inset-0、z 高层），整体盖住三栏
          ├ 汇总页（大字统计 + 证据分布条 + 议程）
          ├ 逐项页（单条一屏 · 3 米可读 · 键盘推进 · 会中拍板）
          └ 驳回大字弹窗（S11 的大字号变体，Esc 只关弹窗，G1''）
          Esc 退出 → 焦点回 S1「汇报模式」按钮；工作台 DOM 不受侵入
```

- **左栏 S-L**：固定窄栏（~240px），项目导航（2.15）。
- **主内容区**：当前项目的看板——S1 项目概览头 / S1b 上传报告 + 项目内报告列表 / S6 过滤器 / S2 卡片流（卡内 S3/S4/S5/S12）。宽度自适应（G14 沿用）。
- **右栏 S-R**：「运行详情」抽屉，默认收起，S1 右端开关钮（2.16）；账本全局，无项目空态下仍可打开（G4'）。
- **DOM/焦点顺序（G13 沿用）**：`<main>` → `<aside S-L>` → `<aside S-R>`，视觉列位由 grid 控制。无路由。
- **当前项目记忆（G7'）**：`localStorage.dp.activeProjectId`，刷新/重启回到最后项目；删除后回退列表首个或无项目空态。状态记忆，非路由。
- **窄屏（<1080px）**：三栏解除为单列，DOM 顺序即视觉顺序；S-L 折为主区上方横向条，S-R 折为主区下方。
- **弹层条款（v6 修订）**：弹窗共两处——S11 驳回理由弹窗（**含其汇报模式大字号变体**，同一规则两种规格）与 S14 删除项目确认，均复用原生 `<dialog>` + `--scrim` 基线与焦点管理约定。**S15 汇报模式是全屏覆盖层**（模式容器，非弹窗/非模态遮罩语义）；S-R 非模态；新建/编辑项目、上传、补充建议、任务编辑、补填理由一切表单 inline。
- S15 打开时工作台仅被覆盖不被修改（回归口径：工作台用例零改动仍绿，PRD Testing）。

### 2.1 S1 项目概览头（v6 增补按钮组）

- 位于主区顶部（统计与通知 chip 不进侧栏，G14 沿用）；显示**当前项目**。
- 标题 = 项目名（`.page-title`）；副题（`.overview-lede`）= 项目 purpose，purpose 为空时显示固定副题 `报告驱动的行动闭环`。
- 元信息行（`.overview-meta`）：`共 {N} 份报告 · 建议 {a} · 已采纳 {b} · 已驳回 {c} · 人工 {n}`（`人工 {n}` = 项目内人工补充项计数，恒显，v4 勘误），后接通知 chip。
- 通知 chip 四态（沿用 `.notify-chip`；数据源 = BoardView.notify 的 `configured` / `imConfigured` / `lastPushedReport`）：
  1. 飞书已配置且已推送 → ok 色 `已推送 · {项目名}/{报告名}`（G5' 短形态）
  2. 飞书已配置未推送 → warn 色 `已配置 · 未推送`
  3. 飞书未配置、webhook 已配置 → warn 色 `未配置飞书 · 文本摘要推送`
  4. 均未配置 → warn 色 `推送未配置`
- **右端按钮组（v6）**：`[汇报模式]`（**主级**：主操作样式、accent 语义——S1 内第一主按钮，会议场景高频入口；触发 S15，见 2.18.1）+ `[运行详情]`（plain 开关钮，`aria-expanded={抽屉开}` + `aria-controls` 指向 S-R；关闭后焦点回开关钮）。快捷键 `P` 等效「汇报模式」按钮。
- 无项目空态（S8-①）无 S1，故无汇报模式入口（引导卡头部只保留「运行详情」开关，G4'）。
- **不出现**校准/teach/学习类文案（负面用例 7）与演示类文案（负面用例 2）。

### 2.2 S1b 报告区（上传报告 + 项目内报告列表）

- **区头**：标题「报告」+ 右侧「上传报告」主按钮 → 触发隐藏 `<input type="file" accept=".md,.txt" multiple>`；上传中按钮 disabled + 「上传中」指示。
- **上传语义**：上传即注册 pending 并**立即异步触发抽取**（不阻塞上传响应，M6-US3）；多文件逐份处理、单份失败不影响其余（G2'）；校验失败（>2MB / 非 .md/.txt / 非 UTF-8 可读）→ 该项 `上传失败：{文件超过 2MB / 仅支持 .md/.txt 文件}`（fail 色，G2'）；**同名上传 = 覆盖文件并按 force 语义重抽**（G1'，不弹「重名确认」；仍处「建议」的抽取项删除重建、已决/含任务项保留，同 G3）。
- **报告列表**（导入时间倒序，G1）：每项 = 文件名 + 导入时间（MM-DD HH:mm）+ 状态 chip + 操作：
  - `待抽取`（queue）+「抽取」按钮（异步触发失败兜底）
  - `抽取中`（queue + 旋转，见 S10）
  - `已抽取`（ok）+「重新生成」两段式：首点变「确认重新生成」，提示逐字 `重新生成将删除该报告中仍处「建议」状态的行动项；已采纳/已驳回/含任务的行动项保留`，再点执行 `force:true`，失焦或 3 秒未点自动还原（G3；M5 文案「重新抽取」废止）
  - `抽取失败`（fail）+ 原因摘要（如 `模型调用超时（120s）`）+「重试」
- 幂等：每份报告每轮只推送一次（键 = `projectId:slug`）；重新生成仅作用抽取项，人工项不受影响；报告文件无单独删除入口（随项目硬删）。

### 2.3 S2 行动项卡片（v4 勘误已并入）

- 卡片骨架沿 `.conclusion-card` 同款（`.action-card`）；整卡头 `<button aria-expanded>`，chevron `▸/▾`。
- 卡头：chip 行（状态：建议=queue/已采纳=ok/已驳回=中性；证据等级四级色标；优先级 高=fail/中=warn/低=queue；effort/scene/lifecycle 值 chip 中性、模型枚举原样中文；所属报告 chip = 项目内报告文件名去扩展名，人工项 =「人工补充」）+ 标题（`.card-title`）+ rationale（副文本）+ 右侧 meta（抽取项 `置信度 {0–100 整数}%`；人工项中性徽标「人工」）。置信度必须由证据派生，禁止模型自评表述。
- 操作区（常显）：「采纳」「驳回」`aria-pressed` 单选（suggested 均未按下）；已决显示留痕 `decidedBy · MM-DD HH:mm · 渠道`（渠道 ∈ 看板/飞书）。
- **改判单向（v4 勘误）**：suggested→adopted/dismissed（驳回经 S11）与 adopted→dismissed（经弹窗）允许；**dismissed→adopted 不允许**——已驳回项无「采纳」钮，恢复走重新生成或人工补充。
- 驳回交互：点「驳回」先开 S11，理由确认才落库；取消/Esc 无变更。已驳回卡展开首块「驳回理由」（看板渠道只读文本；飞书渠道默认值 `卡片驳回（未填理由）` + S12 补填）。无删除行动项入口。

### 2.4 S3 证据展开区

抽取项五段（`.evidence`/`.evidence-block` 沿用）：① 事实（等级 chip + 引用块 `quote-block`：左 3px 等级 ink 色边 + `--soft` 底、原文逐字不加装饰引号 + 一句话说明）② 推导过程 ③ 预期效果 ④ 置信度说明 `置信度由证据派生（证据等级与原文引用决定），非模型自评。` ⑤ 警示行逐字 `证据等级由提取模型自评，未做真实数据重验证`。facts 空（封顶 0.5）显示 `未引用报告事实（置信度已按无事实封顶 0.5）`。
**人工项变体**：无事实块（`人工补充建议，未引用报告事实`）；推导 = 依据原文；无预期效果块；④⑤替换为 `人工补充建议：不参与置信度派生，证据等级固定「经验假设」。`。禁止图表/归因表（G2）。

### 2.5 S4 任务列表与编辑（v4 勘误已并入）

- 仅 adopted 卡内（人工项同权）；标题「任务」。
- 任务行：状态三钮（待办=queue/进行=warn/完成=ok，`aria-pressed` 单选）+ **标题**（主文本）+ 副行 `负责人 {owner} · 截止 {YYYY-MM-DD} · 优先级 {高|中|低} · 备注 {note}`（未填省略）+「编辑」（行内表单预填）。
- 新增表单：**标题\***（error `请填写标题`）、负责人（可选）、截止日（可选 date）、优先级（可选 select 高/中/低，默认中）、备注（可选）；「添加任务」「取消」。无删除；空 `暂无任务，添加第一个执行任务`。

### 2.6 S5 反馈回录表单（v4 勘误已并入）

- 未回录 → 表单：已执行（checkbox 默认勾选）、结果\*（textarea）、指标变化（placeholder 例 `复购率 +2.3pp`）、复盘（textarea）、评分\*（radio 1–5，`5=显著正向效果 · 3=无明显变化 · 1=显著负向`）；「提交反馈」。
- 已回录 → 只读块：`已执行|未执行 · 评分 {n}/5` + 结果/指标变化/复盘 + 「更新反馈」按钮（展开同构表单预填，同端点覆盖保存，一任务一条 upsert）。

### 2.7 S7 演示态（v5 移除）

v1–v4 演示态（「演示数据」chip、说明条、3 条演示行动项、不落库约定）整节退役（PRD + G4'）：demo 数据与相关测试删除。原「无报告」触发由真实态替代：无项目 → S8-①；有报告无密钥 → S9。任何演示形态全站禁现（负面用例 2）。

### 2.8 S8 空态（三种）

1. **无项目空态**（G4'）：主区 `.empty` 引导卡——标题 `尚无项目`、说明 `新建一个项目，在项目内上传报告即可生成看板。`、「＋ 新建项目」卡内展开同构表单；S-L 同步空态；引导卡头部保留「运行详情」开关（账本全局）。**无汇报模式入口**（无内容可汇报）。
2. **报告空态**：标题 `该报告未抽取到行动项`，提示 `报告已解析完成，但未包含可执行建议；可尝试重新生成或检查报告内容。`
3. **过滤空态**：`该过滤条件下暂无行动项`。

| 抽取失败 | S1b 列表项 | `抽取失败：{原因}` | 「重试」 |
| 保存失败 | 列表底部 `role=alert` | `保存失败，已恢复为服务器状态` | 回滚可重试（覆盖全部写操作） |
| 推送降级 | S1 通知 chip | 见 2.1 | 无 |

多报告部分失败互不影响；模型链主备呈现归 S-R。

### 2.10 S10 加载态

单报告抽取中（chip 旋转 + `aria-live="polite"`：`正在抽取行动项，模型调用最长约 2 分钟，完成后自动刷新。`；上传→待抽取→抽取中逐份可见）；首屏骨架（概览头 + 3 卡骨架，无项目时为引导卡骨架）；S-L/S-R 不单独做骨架。

### 2.11 S-EXT 飞书审批卡片（外部表面）

机制（长连接、直审、幂等、留痕、先到先得、过期拒绝）保留。卡片 = title + rationale + 证据摘要（top fact 引用 + 等级 + 置信度）+ 预期效果；按钮 `采纳`/`驳回`（单键直驳，无输入框；卡片渠道 `dismissedReason` 默认 `卡片驳回（未填理由）`，看板 S12 补填）。回执：`已{采纳|驳回}：{title}` / `已按首次点击结果处理：{采纳|驳回}` / `该卡片已处理或已过期，请到看板查看最新状态。`。v5 起按项目触发、摘要带 `【项目名】` 前缀、飞书全局一套。

### 2.12 S11 驳回理由弹窗（G10，弹层之一）

- 触发：点「驳回」（首次或 adopted→dismissed 改判；**S15 内为其大字号变体，见 2.18.3**）。
- 实现：原生 `<dialog>` + `showModal()`（原生 Esc、焦点圈定、aria-modal）；平面卡片（`--surface`/`--border`/`--r-base`/`--shadow-card`）+ `--scrim`；宽 `min(420px, 90vw)`。
- 内容：标题「驳回行动项」+ 行动项标题（只读）+ `驳回理由 *` textarea + helper `至少 2 个字` + [确认驳回]（主操作）[取消]（普通）。
- 校验：≥2 字；不足 error（`role="alert"`，fail）逐字 `请填写驳回理由（至少 2 个字）`，焦点保持 textarea。
- 焦点：打开聚焦 textarea；确认/取消/Esc 关闭回「驳回」钮；提交中 disabled。
- 落库：确认后 dismissed + dismissedReason + 时间/渠道；取消无变更。

### 2.13 S12 补填理由（inline）

dismissed 卡证据区首块「驳回理由」：飞书渠道（默认值）→ `卡片驳回（未填理由）` + 补填输入（label「补填理由」，≥2 字）+ [保存]→只读；看板渠道 → 理由只读不覆盖。失败走 S9。

### 2.14 S13 补充建议表单与人工补充项（G11）

入口：S6 右上「补充建议」主按钮。inline 表单：标题\*、依据\*、场景/周期/优先级/投入可选（「不填」首项，值 = 抽取枚举）；[提交][取消]。提交后创建 `sourceKind=manual`（直挂当前项目，reportId 空）：状态=建议、「人工」徽标、经验假设（灰）、「人工补充」分组、报告 chip「人工补充」；证据区见 2.4 变体；同权闭环；不受重新生成影响。校验 error `请填写{标题|依据}`。

### 2.15 S-L 左栏项目导航

结构（~240px，`<nav aria-label="项目导航">`）：① 「＋ 新建项目」主按钮 → inline 表单（`名称 *` 必填、`目的` 可选 placeholder 例 `这个看板跟踪什么业务`、[创建][取消]、Enter 提交/Esc 收起、error `请填写名称`）② 项目列表（名截断 + `行动项 {n}` 中性 chip + 最近活动 MM-DD HH:mm；当前高亮 accent-soft + `aria-pressed`）③ 当前项操作：`编辑`（aria-label `编辑 {项目名}`，inline 表单预填名称/purpose，[保存][取消]）与 `×`（aria-label `删除 {项目名}` → S14）；非当前项仅 `×`。点击项目 = 切换当前项目（主区整体换数据源）+ 写 `dp.activeProjectId`（G7'）。硬删无归档（proposal 决策 6）。空态 `尚无项目——新建一个开始。`。`×`/`编辑` 独立 focus target 不触发切换。信息组织参考 wb-sidebar，样式 Xanthil。

### 2.16 S-R 右栏「运行详情」抽屉

开关 = S1 右端「运行详情」钮（`aria-expanded`+`aria-controls`）；默认收起、收起不影响主区；非模态（无遮罩不圈焦点，关闭回开关钮）；`<aside aria-label="运行详情">` 头部 = 标题 + 「关闭」钮。内容：① 模型链（主/备 + 模型名 + 密钥 chip 就绪=ok/未配置=fail）② 任务账本用量 chips（**全局**：`模型调用 {n}`·`token 入 {n}`·`token 出 {n}`·`用时 {n}s`）③ 抽取事件时间线（最新在前：时间·事件·报告名·成功条数/失败原因 fail 行）。空 `暂无抽取事件——放入新报告后此处显示。`。与 S9 无密钥条同源不同呈现。

### 2.17 S14 删除项目确认弹窗（弹层之二）

触发 = S-L 项目项 `×`。复用 S11 基线（`<dialog>`+`showModal()`+`--scrim`，`min(420px,90vw)`）。内容：标题 `删除项目` + 项目名（只读）+ 正文逐字 `项目及其报告文件将一并删除，不可恢复。` + [确认删除]（**fail 语义色** `--fail-soft/--fail-line/--fail`）[取消]。焦点：打开聚焦 [取消]（破坏性安全位）；关闭回 `×`；提交中 disabled。确认 → `DELETE /api/projects/:id` 硬删+目录；取消无变更；删除后 G7' 回退。

### 2.18 S15 汇报模式（覆盖层，v6 新增整节）

#### 2.18.1 入口与容器

- **入口**：S1 右端「汇报模式」主级按钮（2.1）；快捷键 **`P`**——仅在工作台主区、无输入焦点时触发（`document.activeElement` 非 input/textarea/select/contenteditable），等效点击。
- **浏览器全屏**：进入时尝试 `document.documentElement.requestFullscreen()`；失败**静默降级**为 CSS 全屏占位（fixed inset-0），功能不依赖 Fullscreen API、不提示错误；退出模式时若处于浏览器全屏则 `exitFullscreen()`。
- **容器**：`position: fixed; inset: 0;` z 高层（盖三栏与 S-R；模式内驳回弹窗再叠其上）；背景 `--bg`（亮色）；自身滚动禁用（单屏内容）；`role="region"` + `aria-label="汇报模式"`。
- **焦点管理**：打开 → 焦点入模式容器（容器 `tabindex=-1` 或首个可聚焦件）；**Esc 关闭 → 焦点回「汇报模式」按钮**（M7-US9）；关闭同时退出浏览器全屏。
- **转场**：进入/退出与页间切换仅 opacity fade，**≤80ms**；`prefers-reduced-motion: reduce` 时禁用。

#### 2.18.2 汇总页（首页）

- **头部**：项目名（~24px，600）+ purpose 副题（`--text-3`，弱化）。
- **大字统计行**：`报告 {N} · 建议 {X} · 高优 {Y} · 已采纳 {Z}`——数字 ~64px（600，`--text`）、标签 0.9rem（`--text-3`）、基线分组；口径：项目全量（N=报告数、X=suggested、Y=suggested 且优先级=高、Z=adopted）。
- **证据分布条**：横向堆叠条（高 18px、pill 圆角、1px `--border-strong` 描边）；四段宽度 = **当前范围**内各证据等级条数占比；段色 = 四级 ink 色（`--ok`/`--navy`/`--warn`/`--text-3`）；计数 0 的段宽 0 不显示；**纯 CSS**（flex + 百分比），不引入图表库。图例：四色点 + 等级名 + 计数（`数据支撑 {n} · 多源佐证 {n} · 逻辑推断 {n} · 经验假设 {n}`，0 计数仍列出）。
- **范围切换**：「待拍板 / 全部」分段单选（chip，`aria-pressed`）：待拍板 = suggested；全部 = 状态分组（suggested → adopted → dismissed）组内同 key。联动议程、分布条、逐项页范围标签。
- **议程清单**：当前范围按 **优先级（高>中>低）> 置信度（降序）> 创建时间（升序）**；行 = 序号（01… mono）+ 标题 + 优先级徽标 + 证据色点；点击/Enter **直达**该逐项页（M7-US2）。
- **底部提示行**（逐字，居中）：`← → 切换 · Esc 退出`
- **空范围（G2''）**：无待拍板项进入 → 议程区逐字 `当前没有待拍板的建议` + 「查看全部」切换入口；**不阻止进入**（复盘仍可用）；此态逐项页不可达（议程空时仅汇总页可达）。

#### 2.18.3 逐项页（主体）

- **单条一屏**：`100dvh` 内自适应；内容超长时**仅引用块内部滚动**（max-height 约束 + overflow-y），标题/置信度/操作钮恒可见。
- **信息结构固定**，自上而下：
  1. **页码指示**：`{当前} / {总数}`（mono ~18px，`--text-3`）+ 范围标签（「待拍板」/「全部」pill chip）；页码 `aria-label="第 {当前} 条，共 {总数} 条"`。
  2. **行动项标题**：`clamp(28px, 4vw, 44px)`、600、`--text`、行高 1.25。
  3. **徽标行**：优先级/投入/场景/周期值 chip 大号（工作台 chip ×~1.2：字号 ~14px、padding 加倍）；配色沿 6.2/6.3。
  4. **证据区**：证据等级 chip（四级大号）+ **置信度大数字 ~56px**（600，`--text`，旁置小标签「置信度」）+ **报告原文引用 blockquote ~24px**（`--soft` 底 + 3px 等级 ink 色左边，逐字、不加装饰引号）+ **推导过程收起可展开**（默认收起触发器「推导过程 ▸」式，展开正文 ~20px；多 fact 逐条列、每条带等级 chip）。
  5. **预期效果行**：`预期效果：{expectedImpact}`（label `--text-3` + 正文 ~20px）。
  6. **来源行**：报告文件名（`--text-3`，~14px）。
- **人工项变体**：置信度位显示「人工」**大徽标**（中性放大 ~40px 高）；证据区固定说明沿工作台逐字 `人工补充建议：不参与置信度派生，证据等级固定「经验假设」。`；无引用块。
- **键盘键位表**（M7-US3；按钮同功能可点）：

  | 键 | 动作 |
  |---|---|
  | `←` | 上一条 |
  | `→` | 下一条 |
  | `Home` / `End` | 首条 / 末条 |
  | `G` | 回汇总页 |
  | `A` | 采纳当前项（suggested 态） |
  | `D` | 驳回当前项 → 打开大字弹窗（suggested 态） |
  | `Esc` | 弹窗打开时只关弹窗（G1''）；否则退出汇报模式 |

- **会中拍板（M7-US6/7）**：
  - 大号按钮：**采纳** = `--ok` 实心底 + 白字（~20px、大 padding；本契约唯一实心钮——PRD「主绿」指定 + 3 米可读）；**驳回** = fail 软底（`--fail-soft`/`--fail-line`/`--fail`，色+文字双通道）。仅 suggested 态显示（可操作性只取决于状态，与范围无关）。
  - **采纳**：A/点 → PATCH adopted（乐观更新）→ 留痕行 `已采纳 · 看板 · {MM-DD HH:mm}` → **800ms 自动前进**；末条 → 回汇总页。
  - **驳回**：D/点 → **大字号驳回弹窗**（S11 大字变体，复用全部 G10 规则：`驳回理由 *` ≥2 字、helper `至少 2 个字`、error 逐字 `请填写驳回理由（至少 2 个字）`、[确认驳回][取消]；规格放大：标题 ~28px、textarea ~20px、宽 `min(560px, 90vw)`；焦点同 S11——打开聚焦 textarea、关闭回驳回大钮；**Esc 只关弹窗不退模式**，G1''）→ 确认 → PATCH dismissed + 理由 → 留痕行 `已驳回 · 看板 · {时间}` → 800ms 前进（末条回汇总）。
  - **失败**：PATCH 失败 → `role="alert"` + aria-live 播报逐字 `保存失败，已恢复为服务器状态`，**停留当前页**不前进、按钮恢复（G4''）。
- **已决项呈现（G3''）**：操作钮区替换为**留痕行**——`已采纳 · {渠道} · {MM-DD HH:mm}` / `已驳回 · {理由摘要}`（理由超长省略号，完整理由回工作台；渠道 ∈ 看板/飞书）。**模式内不提供改判**（只读复盘；改判回工作台）。

#### 2.18.5 可访问性

- 键盘全程可达：进入（P/按钮）、汇总（直达/范围切换）、逐项（←/→/Home/End/G/A/D）、弹窗（textarea/确认/取消）。

## 3. Click paths

### 3.1 主成功路径（M6：新建项目 → 上传 → 闭环）

1. **新建项目**：S-L「＋ 新建项目」→ inline 表单（名称\*、目的可选）→「创建」→ 切换为新项目。（首启平行入口：无项目引导卡。）
2. **上传报告**：「上传报告」→ 选 1..n 个 .md/.txt → 逐份写入并立即异步抽取（上传中→待抽取→抽取中，aria-live）→ 已抽取 → S2 新行动项（建议）；抽取完成后按项目推送（【项目名】摘要）。
3. **看证据**：点卡头 → S3 五段 → 30 秒判断（US2）。
4. **确认**：采纳 → 已采纳 + 留痕 + 任务区；驳回 → S11 弹窗理由 → 已驳回 + 理由留痕（飞书单键驳回 → S12 补填）。
5. **拆任务**：标题\* + 可选项 → 任务行（默认待办）→ 待办→进行→完成。
6. **回录反馈**：表单 → 只读块（「更新反馈」可覆盖）。
7. 改判单向：adopted→dismissed 经弹窗；dismissed 不回采纳。

### 3.2 次级结果路径

加载中（写操作 disabled）；空结果（无报告→报告区引导；0 条→S8-②；过滤无命中→S8-③；无项目→S8-①）；部分结果（多文件单败不连锁；一份报告失败其余照常）；同名上传（覆盖+force，不弹确认）。

### 3.3 显式失败路径

上传失败（重选文件）；抽取失败重试（S-R 时间线同现失败行）；重新生成（G3 两段式）；保存失败（`保存失败，已恢复为服务器状态` 回滚）；飞书降级（通知 chip，不阻塞闭环）。

### 3.4 变更回灌路径（G10/G11）

看板驳回弹窗 / 飞书单键驳回→补填 / 人工补充同权闭环——沿 v5。G12 校准注入项目级过滤，无用户可见路径（负面用例 7）。

### 3.5 工作台路径（项目化）

切换项目（+ `dp.activeProjectId` 记忆/回退）；新建；删除（×→S14→硬删→回退）；编辑项目；运行详情开合。

### 3.6 汇报路径（v6 新增，M7）

1. **进入**：S1「汇报模式」（或 `P`）→ 尝试浏览器全屏（失败静默降级）→ 覆盖层 fade（≤80ms）打开、焦点入容器 → **汇总页**。
2. **开场**：项目名 + 大字统计 + 证据分布条（纯 CSS 四色 + 图例计数）+ 议程（优先级>置信度）——一句话说明今天拍什么（M7-US2）。
3. **过会**：议程直达（或 G 回汇总、←/→ 逐条、Home/End 首末）→ **逐项页**：大字标题 → 徽标行 → 证据区（等级 chip + 置信度大数字 + 引用块 + 推导展开）→ 预期效果 → 来源（M7-US3/4/5）。
4. **拍板**：`A` 采纳 → 留痕 + 800ms 前进；`D` 驳回 → 大字弹窗（≥2 字）→ 确认 → 留痕 + 前进；失败 aria-live 播报并停留（M7-US6/7）。
5. **复盘**：范围切「全部」→ 已决项留痕行（`已采纳 · 渠道 · 时间` / `已驳回 · 理由摘要`）只读（M7-US8）。
6. **退出**：`Esc`（无弹窗时）→ 退覆盖层与浏览器全屏 → 焦点回「汇报模式」按钮（M7-US9）。
- **次级**：空范围进入 → 空议程 `当前没有待拍板的建议` + 「查看全部」（G2''）；Fullscreen 被拒 → CSS 全屏占位照常开会。

## 7. Negative cases（禁止清单；v6 增改以粗体标出）

1. **旧形态禁现**：结论卡、推导链路、ECharts 图表、归因明细、跨周对照/周趋势、期次/数据窗口文案。
2. **演示形态全站禁现**：S7 退役后无任何「演示数据/示例报告」chip、说明条、演示行动项或示例冒充；无项目首启 = 引导卡；无密钥 = S9 错误条。
3. **证据警示不可省（抽取项）**：逐字 `证据等级由提取模型自评，未做真实数据重验证`（S3 与 S6 尾注）；人工项以变体说明替代。
4. **弹层两处为限（v6 修订）**：仅 S11 驳回理由弹窗（**含 S15 大字号变体**）与 S14 删除确认两处弹窗；S15 是全屏覆盖层（模式容器）非弹窗；S-R 非模态；其余一切 inline；不发明 PRD 外界面（无 JuanerAI 入口占位、无项目归档/软删、无项目级审批人、无行动项删除钮、无路由）。
5. **置信度表述**：只能「由证据派生」；人工项只显「人工」徽标，不得伪造百分比。
6. **quote 逐字**：引用块逐字呈现报告原文（工作台与 S15 大字版同规），不摘要、不转写、不加装饰引号。
7. **G12 校准注入无用户可见界面**（项目级过滤同样不可见）；「校准/teach/调优/学习」不入用户文案。
8. **飞书卡片无输入框**：驳回单键直驳；理由输入只在看板（弹窗/补填）。
9. **布局纪律**：左栏 = 项目导航，不得出现全局报告列表/目录扫描形态；S-L 点击 = 切换当前项目（非过滤聚焦、非路由）；S-R 收起不留残留；S1 统计/通知留主区；不照抄 reports-factory 样式；跨项目数据不串。
10. **上传纪律**：仅 .md/.txt 多文件、≤2MB；同名 = 覆盖 + force（不弹重名确认）；单败不连锁；报告删除只随项目硬删。
11. **汇报模式纪律（v6 新增）**：
    - 覆盖层内**不出现**工作台三栏、项目导航、上传按钮、任何编辑表单（任务/反馈/补充建议/补填/项目新建编辑）——S15 只含汇总页与逐项页两态及驳回大字弹窗；
    - **不做暗色**（亮色放大版，proposal 决策 3；DESIGN.md：暗色需单独设计，未设计即不交付）；
    - **无装饰性大色块与渐变**（层级只靠字号/间距/四色证据标；分布条是信息图形非装饰）；**不重新引入图表库**（分布条纯 CSS）；
    - 无演讲者备注、打印/PDF 导出、多项目联播、动画丰富化（fade ≤80ms 为上限）；
    - 模式内已决项**不可改判**（留痕行只读；改判回工作台）；逐项页除引用块外**不得出现滚动**；
    - 工作台 DOM/语义不被模式侵入（覆盖不修改；退出后工作台用例零改动仍绿）。
